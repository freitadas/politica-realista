# Mandato — versão 3 (salvamento)

- Salvamento automático a cada mudança renderizada na campanha;
- Botão Salvar visível no celular e no desktop;
- Verificação de sucesso ou falha do armazenamento local;
- Exportação de backup JSON e importação no início da partida;
- Compatibilidade com salvamentos da versão anterior (`mandato_save_v1`);
- Conserva a estrutura plana do GitHub: `index.html`, `app.js`, `styles.css` na raiz.

## Atualização no GitHub

Substitua **index.html, app.js e styles.css** no repositório. Mantenha `Publish Directory` = `.` no Render. Não remova seu salvamento do navegador nem limpe o armazenamento do site.

**Limitação:** localStorage é específico de cada navegador e endereço, não sincroniza dispositivos; exporte backup para transferência. O backup não é armazenamento em nuvem.

Partidos e políticos têm nomes reais; pesquisas, eventos e episódios de corrupção são fictícios.
