# Mandato — Simulador Político

Jogo de estratégia política para navegador. A disputa ocorre na fictícia República de Aurélia.

## O que já existe

- campanha presidencial de 24 semanas;
- 4 regiões eleitorais com pesos e temas diferentes;
- pesquisas nacionais dinâmicas;
- orçamento de campanha;
- reputação e cobertura da imprensa;
- organização territorial;
- campanha digital;
- treinamento para debates;
- ações semanais;
- propostas programáticas com efeitos diferentes;
- negociação de alianças;
- eventos políticos aleatórios;
- adversários controlados pelo jogo;
- eleição final com componente probabilístico;
- salvamento local no navegador;
- interface responsiva para desktop e celular.

## Abrir localmente

Abra `public/index.html` no navegador.

## GitHub

Crie um repositório e envie estes arquivos mantendo a estrutura:

```text
politica-realista-game/
├─ public/
│  ├─ index.html
│  ├─ styles.css
│  └─ app.js
├─ render.yaml
├─ .gitignore
└─ README.md
```

## Render

O projeto inclui `render.yaml` para um **Static Site**.

A configuração usada é:

- Runtime: Static
- Build Command: `echo "Static site ready"`
- Publish Directory: `./public`

Ao conectar o repositório do GitHub ao Render, novas alterações na branch vinculada podem gerar novos deploys automaticamente.

## Observação

Todos os nomes, partidos, acontecimentos, regiões e cenários políticos do jogo são fictícios.
